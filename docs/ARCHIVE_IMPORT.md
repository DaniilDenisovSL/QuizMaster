Мітки дозволяють переглядати та завантажувати кожний стан коду; це не підтверджені релізи чи оригінальні дати розробки. `main` і `develop` зберігають фінальний код версії 6, доповнений документацією імпорту. Старі архіви повторно не оголошуються протестованими.

Підтверджені відмінності: у v2 оновлено підключення форм і backend; у v3 змінено банк запитань, навігацію, паузу таймера та елементи інтерфейсу. Авторство цих змін не визначається під час імпорту.

Вихідний код, ресурси та проєктні файли кінцевої версії скопійовано з v6 без змін. README оновлено для спільного репозиторію; збережено наявні CONTRIBUTING.md, .gitignore та попередню історію develop. Журнали `qa-logs` і попередній звіт QA перенесені з архіву як історичні матеріали; вони самі по собі не є доказом повторної перевірки під час імпорту.

До Git не включено локальні `.vs`, `bin`, `obj`, `.user` та копії `Design/backup`. Документація дизайну може посилатися на ці локальні резервні копії, яких у спільному репозиторії немає. Старі `.patch` збережено для довідки.
