# Quiz Master


Навчальний командний проєкт: вікторина на C# Windows Forms.


## Стан проєкту


Репозиторій підготовлено для початку командної розробки. Код застосунку ще не додано. Можливості нижче заплановані та ще не реалізовані.


## Заплановані можливості


- 10 запитань із чотирма варіантами відповіді.
- Категорії: ігри, програмування, спорт, фільми, загальні знання.
- Рівні складності, таймер, бали, життя та серія правильних відповідей.
- Випадковий порядок запитань і відповідей.
- Екран результатів і таблиця рекордів.


Значення таймера, кількість життів і правила балів команда погоджує в технічному завданні.

## Запуск після додавання коду


1. Клонувати репозиторій на Windows.
2. Відкрити рішення .sln або .slnx у Visual Studio з компонентом «Розробка класичних програм .NET».
3. Установити SDK .NET або пакет розробника .NET Framework, вказаний у .csproj.
4. Відновити пакети NuGet і зібрати рішення.
5. Вибрати WinForms-проєкт стартовим і натиснути F5.


Версію .NET і назву рішення буде додано разом із кодом. Запуск ще не перевірено.
