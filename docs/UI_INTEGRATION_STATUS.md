# Підключення інтерфейсу до backend

Форми тепер використовують наявні `QuestionBank`, `QuizSession`, `QuizCatalog` та `LeaderboardStore`. Файли backend і правила гри не змінено.

Причина попереднього демонстраційного режиму: backend був доданий до проєкту як окремі класи, а їх підключення до форм залишилося лише пропозицією у `UI_INTEGRATION.patch`. Цю пропозицію більше не потрібно застосовувати поверх поточної реалізації.

## Що працює

- `MainMenuForm` завантажує банк питань і передає обрані категорію, складність, ім’я та перемішування у справжню сесію.
- `GameSetupForm` показує поточні правила з `QuizOptions`.
- `QuizForm` показує питання зі сесії та прив’язує кнопки до стабільних ID відповідей. Відповіді перевіряє backend; UI лише показує його рішення.
- Оновлення часу опитує `GetState()` на UI-потоці. Окремого незалежного відліку немає. Після відповіді чи виходу таймер зупиняється.
- Після завершення гри `ResultsForm` показує фактичний `QuizResult`. Завершення через вичерпання життів також обробляється. Рекорд зберігається один раз.
- При виході до меню активна сесія переривається і не зберігається як завершена.
- `LeaderboardForm` завантажує збережені записи, фільтрує їх за категорією та показує порожній список, якщо результатів ще немає. Масив `demoRows` видалено.
- При помилці збереження сам підсумок гри не губиться; інтерфейс повідомляє, що рекорд не вдалося зберегти.

Прибрано демонстраційні підписи та фіксовані підсумки з усіх форм. Дизайн, іконки, центрування, F11 та плавна поява збережені. У кнопок додано відображення кольорів правильної/неправильної відповіді у заблокованому стані.

Зберігання рекордів використовує шлях, визначений backend: `LocalApplicationData/QuizMaster/leaderboard.json`. Дані користувача під час перевірок не очищалися; UI-перевірки використовували окремі тестові сховища.

Перевірено 10 наявних backend-перевірок та 21 сценарій UI-інтеграції: усі категорії/складності, завершення проходження, вичерпання життів, помилку збереження, таймаут, вихід, фільтр рекордів і запуск через головне меню.

Після оновлення зупини попередній запущений екземпляр і запусти проєкт через F5. Попередній код форм збережено в `Design/backup/before-backend-ui-integration`.
